Excel Dashboard Description: Public Libraries Analysis
This interactive Excel dashboard was created to visualize and analyze key metrics related to public libraries across various counties. The dashboard aims to provide clear insights into library usage trends, circulation data, financial expenditures, and resource distribution, using well-designed visuals and pivot-based interactivity.

🧩 Dashboard Components:
📈 Public Library Visits vs Fiscal Years:

This line chart tracks the number of library visits over the fiscal years.

It helps identify engagement trends—highlighting peak years and sudden declines, such as the noticeable drop around 2020, likely due to the pandemic.

Users can filter the data by fiscal year using the slicer.

🥧 Distribution of Libraries Across Counties:

A 3D pie chart shows the proportion of public libraries distributed among different counties such as Fairfield, Hartford, and New Haven.

Each slice visually represents how many libraries exist in each county, offering quick geographic comparison.

🍩 County vs Total Library Circulations:

This doughnut chart displays the total number of items circulated by libraries in each county.

It helps identify which counties are most active in terms of borrowing and resource usage.

This reflects community engagement with library services.

💸 Operational Expenditures Comparison:

The horizontal bar chart compares how much each county spends on operating its public libraries.

It helps assess which regions prioritize funding and how financial resources are allocated across locations.

📚 Library Collection Sizes Across Libraries:

A scatter plot is used to display the collection sizes of individual libraries.

Each dot represents a library, and the position reflects the number of items in its collection.

This helps in identifying resource-rich or under-resourced libraries, as well as any outliers.
